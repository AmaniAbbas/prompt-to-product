# Task Generation Rules

- Never invent schema fields.
- Never infer relationships absent from SCHEMA.md.
- Acceptance criteria must be directly traceable to the spec.
- Every DB-related task requires schema cross-check verification.
- Tasks must distinguish:
  - current scope
  - future-proofing
  - explicit exclusions
- Acceptance criteria must be objectively testable.
- Tasks must avoid combining unrelated architectural concerns.
- If schema ambiguity exists, stop and request clarification.
